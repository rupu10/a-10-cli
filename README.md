# Project Name

RECIPE BOOK

A modern web application built with the MERN stack (MongoDB, Express, React, Node.js) featuring responsive design, smooth animations, and interactive UI components.

## Features

- **Fullstack Architecture**: MongoDB database with Express.js backend and React frontend
- **Responsive UI**: Built with Tailwind CSS and DaisyUI components
- **Client-side Routing**: Implemented with React Router
- **Animations**: Swiper.js for carousels and sliders
- **Alerts & Notifications**: SweetAlert2 for beautiful popup messages
- **Icons**: React Icons library for vector icons
- **Typewriter Effect**: React Simple Typewriter for animated text
- **Environment Variables**: Secure configuration with dotenv
- **CORS**: Properly configured for API security

## Technologies Used

### Frontend
- React.js
- React Router
- Tailwind CSS
- DaisyUI (Tailwind component library)
- Swiper.js
- SweetAlert2
- React Icons
- React Simple Typewriter

### Backend
- Node.js
- Express.js
- MongoDB (with Mongoose ODM)
- CORS middleware
- dotenv for environment variables

## Installation

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (local or Atlas URI)
- npm or yarn
